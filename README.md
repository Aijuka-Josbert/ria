# Ria's Golden Exam Vault 🎓✦

Plain HTML/CSS/JS — no install, no build. Open `index.html` directly or host on GitHub Pages.

## What's inside
- **Midnight Emerald & Burnished Gold Honors Lounge** design with drifting stardust canvas, live climbing **Grade Forecast** (`A-` → `👑 LEGENDARY`), synthesized sound effects, and **Luck Aura** toggle.
- **6 Brand-New Exam Trials**:
  1. **Myth Buster Deck** — 5 rapid-fire Cap or Facts exam claims
  2. **Falling Grade Catcher** — slide the graduation cap (touch, mouse, or arrow keys) to catch `A+`, `💯`, `⭐`, `🍀` and dodge distractions
  3. **Flow State Lock** — precision timing needle calibration (tap or Spacebar)
  4. **Secret Code Decoder** — interactive letter-tile unscramble (`ACED`, `FOCUS`, `GENIUS`) with Hint support
  5. **Distraction Shield** — 3×3 whack-a-distraction exam desk grid with bonus `🍀` charms
  6. **Exam Battle Kit Builder** — 3-slot custom loadout engraved onto her final diploma
- **Brand-New Vault Finale**:
  - **Royal Wax Seal Envelope** (press-and-hold radial melt ring or tap 3×)
  - **Canvas Metallic Gold Scratch-Off Ticket** (rub away real gold foil with finger/mouse to reveal *PURE DISTINCTION*)
  - **Honors Celebration** with synthesized Victory Anthem, fireworks, typed personal letter, **Pocket Exam-Day Blessing Generator**, 4 redeemable exam-season passes, and an engraved **Official Exam Conqueror Diploma**.

## Customize (`script.js`, top `CONFIG`)
Edit `nickname`, `fullName`, `letter`, `blessings`, and `passes` at the top of `script.js`.

## Testing Shortcuts
- Open `index.html?success` (or `?unlock` / `?surprise`) to jump straight to the Golden Wax Seal Vault.
- Tap `EXAM PASS // RIA` in the top-left 5 times for the same shortcut.
